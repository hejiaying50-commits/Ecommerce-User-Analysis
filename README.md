# Ecommerce User Behavior Analysis

## 项目名称

电商用户行为分析与转化漏斗优化项目

## 核心结论

1. 浏览行为远高于购买行为，整体转化率偏低，说明用户从兴趣到下单的路径存在明显损耗。
2. 用户活跃高峰集中在晚间时段，可用于营销投放排期、消息触达和直播活动安排。
3. 加购到购买环节流失明显，是转化优化重点，适合设计购物车召回、限时优惠和下单提醒策略。
4. 高价值用户占比较低，需强化会员运营、复购激励和重点用户维护策略。

## 项目背景

本项目基于淘宝公开用户行为数据集 `UserBehavior.csv`，围绕用户浏览、收藏、加购、购买四类行为，完成数据清洗、EDA 分析、转化漏斗分析、用户分层分析和 Power BI 看板搭建，目标是为电商运营增长与用户转化优化提供数据支持。

## 业务价值

本项目重点回答以下业务问题：

1. 用户在浏览、收藏、加购、购买路径中的关键流失点在哪里。
2. 用户活跃高峰出现在什么时间段，是否可以支持投放节奏优化。
3. 哪类用户更值得重点运营，如何识别高价值用户与沉睡用户。
4. 如何将分析结果沉淀为可复用的数据文件、SQL 脚本和 Power BI 看板。

## 分析框架

### AARRR / 指标体系说明

本项目虽然使用的是用户行为明细数据，但分析思路可映射到 AARRR 框架中的关键环节：

* `Acquisition`：通过浏览行为 `pv` 观察用户进入商品页后的初始触达规模。
* `Activation`：通过收藏 `fav` 和加购 `cart` 观察用户兴趣与购买意愿的形成过程。
* `Revenue`：通过购买行为 `buy` 衡量最终转化结果。
* `Retention`：通过 RFM 和复购分析观察用户持续购买与价值沉淀情况。
* `Referral`：原始数据不包含分享、邀请等字段，因此本项目未覆盖推荐传播分析。

项目核心指标包括：

* 总用户数
* 总行为数
* 总购买数
* 浏览到购买转化率
* 收藏到购买转化率
* 加购到购买转化率
* 用户活跃高峰时段
* 用户分层结构
* 复购用户分布

## 方法说明

### 为什么抽样 500 万条

原始数据体量较大，完整数据超过本地轻量作品集场景的处理上限。为兼顾本地复现效率、Notebook 可运行性和作品集可展示性，本项目在数据量超过 500 万行时进行随机抽样，`random_state=42` 用于保证结果可复现。

### 为什么采用简化版 RF 模型

原始数据只包含用户行为、商品和时间信息，不包含成交金额字段，因此无法构建完整 RFM 中的 `Monetary` 维度。本项目采用简化版 `RF` 模型：

* `Recency`：距离最近一次购买的天数，越小越好
* `Frequency`：购买次数，越大越好

虽然少了金额维度，但仍可用于识别高价值用户、潜力用户和沉睡用户。

### 为什么要做漏斗分析

漏斗分析主要用于识别关键流失环节。相比只看总购买数，漏斗能更清晰地回答：

* 用户在哪个阶段流失最明显
* 收藏和加购是否有效推动购买
* 后续优化应该优先落在哪个环节

### 为什么要做活跃时段分析

活跃时段分析用于支持投放与触达策略，例如：

* 优惠券发放时间
* App Push 或短信触达时间
* 直播活动排期
* 购物车召回消息发送窗口

## 分析内容

1. 数据清洗：字段命名、缺失值检查、重复值处理、时间字段转换。
2. 用户行为分布分析：统计 `pv`、`fav`、`cart`、`buy` 的行为量级。
3. 用户活跃时间分析：按小时统计用户行为数量，识别高活跃时段。
4. 转化漏斗分析：构建浏览 → 收藏 → 加购 → 购买的转化链路。
5. RF 用户分层分析：基于最近购买时间和购买频次划分用户层级。
6. Power BI 可视化看板：沉淀为可展示的作品集看板。

## 增强分析

### 1. 复购分析

除了单次购买转化外，本项目建议进一步统计复购用户分布，例如：

* 购买 1 次用户占比
* 购买 2 次及以上用户占比
* 高频购买用户 Top N

这类分析有助于判断当前增长是依赖新用户首购，还是已经形成一定复购基础。

### 2. Cohort 分析思路

原始项目当前未在 Notebook 中完整实现 cohort 留存表，但推荐在后续增强版本中补充：

* 以用户首次购买日期作为 cohort 起点
* 观察次月、次周或后续周期的购买留存
* 评估不同批次用户的持续转化表现

如果后续用于冲击更强的实习岗位，cohort 分析会显著提升项目的方法深度。

### 3. 分析局限性

本项目也存在明确边界，面试时建议主动说明：

* 原始数据不包含成交金额，因此无法构建完整 RFM 中的 M 维度。
* 数据来自公开样本，不能完全等同于真实电商平台生产环境。
* 抽样策略更适合趋势分析与作品集复现，不适合精确结算级分析。
* 数据字段中缺少渠道、活动、价格、用户画像等信息，因此无法做更细的归因与精细化分群。

## 运行方式

1. 下载 `UserBehavior.csv`
2. 放入 `data` 目录
3. 安装依赖：

```bash
pip install -r requirements.txt
```

4. 启动 Jupyter：

```bash
jupyter notebook
```

5. 依次运行：

* `notebook/data_clean.ipynb`
* `notebook/eda_analysis.ipynb`

6. 打开 Power BI，导入以下文件制作看板：

* `data/clean_user_behavior.csv`
* `data/funnel_data.csv`
* `data/hourly_activity.csv`
* `data/rfm.csv`
