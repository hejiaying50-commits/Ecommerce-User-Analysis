# 项目总结

## 1. 项目背景

本项目基于淘宝公开用户行为数据集，对用户浏览、收藏、加购、购买等行为进行系统分析，目标是识别用户转化路径中的关键流失环节，并通过RFM模型完成用户价值分层，为电商运营优化提供数据支持。

## 2. 数据说明

原始数据文件为 `UserBehavior.csv`，主要字段包括：

* `user_id`：用户ID
* `item_id`：商品ID
* `category_id`：商品品类ID
* `behavior_type`：行为类型，包含 `pv`、`fav`、`cart`、`buy`
* `timestamp`：行为发生时间戳

由于原始数据量较大，项目中设计了数据抽样逻辑，当数据量超过500万行时随机抽样500万行，以保证本地分析效率和项目可复现性。

## 3. 分析流程

1. 读取原始CSV并补充字段名。
2. 检查数据规模、字段类型、缺失值和重复值。
3. 将时间戳转换为标准时间，并扩展日期、小时、星期字段。
4. 输出清洗结果供EDA和Power BI复用。
5. 完成行为分布、活跃时段、转化漏斗和RFM分析。
6. 导出看板所需数据文件，支持Power BI可视化。

## 4. 核心指标

项目核心指标包括：

* 总行为数
* 总用户数
* 购买行为数
* 浏览到购买转化率
* 收藏到购买转化率
* 加购到购买转化率
* 用户活跃高峰时段
* 高价值用户占比

## 5. 转化漏斗分析

转化漏斗覆盖四个关键阶段：浏览、收藏、加购、购买。通过统计各阶段行为量，可以识别用户在转化链路中的流失位置。

重点关注以下问题：

* 浏览量是否远高于后续行为量
* 收藏与加购是否对购买形成有效促进
* 哪一个阶段流失最严重
* 是否存在需要优化的商品详情页、优惠策略或下单流程

## 6. RFM用户画像分析

项目基于购买行为构建简化版RFM模型，其中：

* `Recency`：距离最近一次购买的天数，越小越好
* `Frequency`：用户购买次数，越大越好

通过分位数打分后，将用户划分为：

* 高价值用户
* 潜力用户
* 沉睡用户

该结果可用于会员运营、精准营销、召回策略和复购提升方案设计。

## 7. Power BI看板说明

Power BI看板建议拆分为五个页面：运营总览、转化漏斗、活跃时间、用户画像和业务结论。数据源来自清洗与分析阶段导出的CSV文件，便于快速搭建作品集展示页面。

## 8. 业务优化建议

1. 针对浏览量高但购买率低的商品，优化详情页内容和促销信息。
2. 在晚间高活跃时段集中投放优惠券、直播活动或消息提醒。
3. 针对加购未购买用户设计限时折扣和购物车召回策略。
4. 对高价值用户设置会员权益和专属优惠，提升复购率。
5. 对沉睡用户制定召回活动，降低用户流失。

## 9. 简历包装话术

项目名称：电商用户行为分析与转化漏斗优化项目  
技术栈：Python / Pandas / SQL / Power BI / Excel
